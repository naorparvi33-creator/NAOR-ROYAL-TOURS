# Open World Sniper (שם זמני)

משחק עולם פתוח למובייל ב-Godot 4.7.2 (Mobile renderer, Vulkan), מכוון ל-Galaxy S23 Ultra.

## איך מתקינים את ה-APK בטלפון

1. מעבירים את הקובץ `OpenWorldSniper.apk` לטלפון (WhatsApp לעצמך, Google Drive, או כבל USB).
2. פותחים אותו מתוך "הקבצים שלי" (My Files) בטלפון.
3. בפעם הראשונה אנדרואיד ישאל אם לאפשר התקנה ממקור לא ידוע. מאשרים לאפליקציה שממנה פתחת את הקובץ ("אפשר מהמקור הזה").
4. לוחצים "התקן". אם מופיעה אזהרה של Play Protect, לוחצים "פרטים נוספים" ואז "התקן בכל זאת" (זה קורה כי האפליקציה לא מגיעה מהחנות).
5. כל גרסה חדשה נחתמת באותו מפתח, אז אפשר להתקין אותה מעל הקודמת וההגדרות נשמרות.

## בנייה

```bash
cd game
./build_android.sh            # בונה build/OpenWorldSniper.apk
./build_android.sh --install  # בונה ומתקין בטלפון שמחובר ב-USB (צריך USB debugging)
```

צריך: Godot 4.7.2 עם תבניות ייצוא ל-Android, JDK 17 ומעלה, ותיקיית Android SDK עם build-tools ו-platform-tools.
הסקריפט מוצא את ה-SDK לבד (`ANDROID_SDK_ROOT`, `~/Android/Sdk` או `/usr/lib/android-sdk`), בודק קבצים שלא בשימוש ומדפיס את גודל ה-APK.

קובץ החתימה `android/sideload.keystore` נועד רק להתקנה ידנית (sideload). לפני פרסום בחנות צריך ליצור מפתח חדש וסודי.

## מבנה

| תיקייה | תפקיד |
|---|---|
| `core/` | הגדרות שנשמרות, שפה (עברית/אנגלית), קלט מאוחד (מגע, שלט, מקלדת), ביצועים (מגבלת FPS, רזולוציה דינמית, חום) |
| `player/` | דמות, תנועה, טיפוס ודילוג אוטומטיים, מצלמת גוף שלישי |
| `weapons/` | אגרופים, אקדח, רובה סער; `weapons/sniper/`: רובי צלפים עם בליסטיקה אמיתית, סקופ, מטווח 100-1000 מ׳ |
| `world/` | סצנה ראשית ושטח בדיקה |
| `world/env/` | מחזור יום ולילה (שמש, ירח, כוכבים, פנסי רחוב, חלונות מוארים, פנסי רכב) ומזג אוויר (בהיר, מעונן, גשם, סערה, כבישים רטובים, קול גשם ורעמים) |
| `vehicles/` | רכבים: סדאן, האצ'בק, ספורט, טנדר 4x4, מסחרית ואופנוע, כל אחד עם התנהגות, גיר, צליל מנוע וצופר משלו; סימני בלימה ועשן צמיגים, מעיכות ופנסים שבורים, שריפה ופיצוץ, מצלמת מכסה מנוע וגוף ראשון (הקשה כפולה במסך), היגוי בהטיה וסיוע היגוי |
| `traffic/` | תנועת רכבים: נהגי AI בנתיבים, רמזורים, צפירות, תאונות וחטיפת רכב |
| `world/interiors/` | בניינים שנכנסים אליהם: דירת מסתור (מיטה, ארון, מוסך), חנות נשק, חנות בגדים, מסעדה, בית חולים, תחנת משטרה, מגדל עם מדרגות לגג |
| `ui/` | שליטת מגע, כוונת, תפריט הגדרות, עורך פריסת כפתורים |
| `ui/menus/` | מסך פתיחה עם טיסת מצלמה מעל העיר, תפריט השהיה, קרדיטים, מצב צילום, חיווי פגיעה בשולי המסך ורטט |
| `core/quality.gd` | איכות גרפיקה (אוטומטי / נמוכה / בינונית / גבוהה), חיתוך לפי מרחק לכל בלוק, צפיפות אנשים (`quality_preset`, `npc_density`) |
| `core/ambience.gd` | רעשי עיר, ציפורים ורוח, צעדים לפי משטח, צלילי נשק וממשק, מוזיקת קרב שמתגברת בזמן לחימה |
| `missions/` | קמפיין סיפור (8 פרקים), עבודות צד חוזרות, 20 פסלונים נסתרים, קפיצות פעלולים, אירועי רחוב |

## קמפיין ותוכן צד

- **סיפור "עיר של זכוכית"**: שמונה פרקים שנפתחים לפי הסדר. נקודת ההתחלה של הפרק הבא מסומנת בעמוד אור כחול-סגול (עבודות הצד בצהוב).
  ליווי רכב עד, מרדף, הגנה על מוסך מפני גלי תוקפים, התגנבות מול שומרים עם קונוס ראייה, חוזה צליפה מרחוק, משלוח שביר נגד הזמן, איסוף ראיות ועימות אחרון מול ברזל.
  הדיאלוגים מופיעים בתיבה (שם הדובר + שורה); הקשה מדלגת, ואם לא נוגעים הם מתקדמים לבד.
- **עבודות צד**: משלוח, חיסול, איסוף כסף, מרוץ ונהג מונית. כל השלמה מעלה את התשלום ב-10% (עד פי 2).
- **20 פסלוני ינשוף מזהב** בסמטאות, בחניות ובפינות העיר. נאספים בהליכה או בנסיעה דרכם.
- **6 קפיצות פעלולים**: רמפות מפוספסות בנתיב הימני של כבישים. קפיצה מהירה מוצגת בהילוך איטי, ונחיתה נקייה משלמת לפי המרחק.
- **אירועי רחוב אקראיים**: שוד ברחוב ורכב מילוט.
- ההתקדמות נשמרת ב-`user://save.cfg` (מקטע `campaign`).

## נכסים ורישיונות

- טקסטורות (דשא, אדמה, בטון, טיח, רעפים, עץ, קליפת עץ, סלע, בד, עור) ושמיים: [Poly Haven](https://polyhaven.com), רישיון CC0.
- דמויות אנושיות: MakeHuman / MPFB2 (רישיון CC0), נוצרות במחולל שבתיקייה `tools/chargen`.
- רהיטים סרוקים בפנים הבניינים (ספה, כיסא, שולחן צד, מדפים): Poly Haven, רישיון CC0.
- אובייקטי רחוב סרוקים (תריסים, מדרגות חירום, פחים, רכב מכוסה, ספסל): Poly Haven, רישיון CC0.
- נשק, עצים, דקלים, סלעים ודשא: נוצרים בקוד או בסקריפט Python.
- כל הצלילים והמוזיקה: סינתזה ב-Python (`tools/audiogen/make_sounds.py`, `tools/audiogen/make_polish_sounds.py`), בלי דגימות.
- רכבים, אופנוע ונהג: נבנים בקוד (`vehicles/car_mesh.gd`). צלילי מנוע, צופר, חריקת צמיגים, אש ופיצוץ: `tools/audiogen/make_vehicle_sounds.py`. מספרי הרישוי מומצאים.
- גופן: Noto Sans Hebrew (רישיון SIL Open Font License 1.1).
- `icudt_godot.dat`: נתוני ICU מתוך Godot (רישיון Unicode). נדרש כדי שעברית תוצג נכון מימין לשמאל.
