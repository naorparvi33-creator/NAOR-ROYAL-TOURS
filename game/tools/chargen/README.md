# מחולל הדמויות

יוצר דמויות אנושיות מציאותיות עם שלד למשחק, באמצעות MakeHuman (התוסף MPFB2, רישיון CC0) בתוך Blender כספריית Python.
הכול פרוצדורלי: אין שימוש בתמונות של אנשים אמיתיים. הפנים נוצרות מעשרות "מטרות" פנים של MakeHuman (אף, פה, סנטר, עיניים, לחיים, אוזניים, צורת ראש) במשקלים אקראיים לפי `seed`, וכל הטקסטורות מצוירות בקוד (numpy).

דרישות: `pip install bpy` (Blender 5.x) ו-`git clone https://github.com/makehumancommunity/mpfb2 /tmp/mpfb2`.

```bash
./cast.sh                 # player + ped_01..ped_16 בתיקייה assets/characters (JOBS=3 לבנייה מקבילית)
./cast.sh ped_07 ped_12   # רק דמויות מסוימות
cd ../.. && godot --headless --import . && python3 tools/chargen/fix_imports.py && godot --headless --import .
```

`fix_imports.py` מעביר את הטקסטורות שגודו מחלץ מה-glb לדחיסת VRAM (ETC2/ASTC בטלפון) ומסמן את מפות הנורמל.

## מה כל דמות כוללת

* **גוף ופנים**: גוף MakeHuman עם 53 עצמות (`game_engine`, שמות העצמות לא משתנים). הגוף מצומצם (decimate) לפני חיתוך הבגדים, בשני מעברים, כך שלפנים נשאר בערך שליש מהמשולשים.
* **עור** (1024): גוון בסיס עם כתמיות, נקבוביות, אדמומיות בלחיים ובאף, צל מתחת לעיניים, נמשים, שפתיים/שפתון, ציפורניים, גבות בקווי שיער, זיפים/זקן מצוירים, קרקפת צבועה מתחת לשיער, כתמי גיל, ו-**Ambient Occlusion** שנאפה ב-Cycles (ארובות עיניים, נחיריים, אוזניים, צווארון). מפת נורמל משותפת של נקבוביות.
* **עיניים**: טקסטורה לכל דמות: קשתית בסיבים רדיאליים בצבע לבחירה, טבעת כהה, אישון, לובן עם ורידים עדינים. ריסים מהגאומטריה של MakeHuman.
* **שיער**: `bald / buzz / short / medium / long / ponytail / bun`, בטקסטורת סיבים שזורמת מהקודקוד. שיער ארוך הוא "וילון" שנבנה סביב הראש ונדחף מחוץ לגוף ולבגדים; קוקו וקוקו-גולגול הם גאומטריה פשוטה. קו שיער נסוג (`hairline`).
* **בגדים**: `tshirt / longsleeve / tank / jacket` (פתוח מלפנים, חולצה מתחת) `/ hoodie` (כיס, שרוכים, קפוצ'ון מגולגל) `/ dress`, ומכנסיים `jeans / trousers / shorts / skirt`. כל הבגדים חולקים טקסטורה אחת לכל דמות, שמצוירת ממפת מיקומים שנאפתה על הבגד הסופי: פסים, משבצות, הדפס גאומטרי, שרוולים בצבע אחר, תפרים, כיסים, דהייה של ג'ינס, חגורה.
* **נעליים**: `sneakers` (סוליה לבנה) / `boots` / `flats`.
* **אביזרים**: משקפיים (`clear` / `sun`), כובע מצחייה / כובע גרב, תיק גב.
* **תקציב**: הולכי רגל ~9,000 משולשים (`tris`), השחקן 15,000; טקסטורות עד 1024; 6-9 חומרים.

כל הפרמטרים מתועדים בראש `build_character.py`; הליהוק נמצא ב-`cast.sh`.
