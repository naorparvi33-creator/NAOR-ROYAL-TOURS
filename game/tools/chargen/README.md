# מחולל הדמויות

יוצר דמויות אנושיות מציאותיות עם שלד למשחק, באמצעות MakeHuman (התוסף MPFB2, רישיון CC0) בתוך Blender כספריית Python.
הכול פרוצדורלי: אין שימוש בתמונות של אנשים אמיתיים. הפנים נוצרות מעשרות "מטרות" פנים של MakeHuman (אף, פה, סנטר, עיניים, לחיים, אוזניים, צורת ראש) במשקלים אקראיים לפי `seed`, וכל הטקסטורות מצוירות בקוד (numpy, העזרים ב-`texlib.py`).

דרישות: `pip install bpy` (Blender 5.x) ו-`git clone https://github.com/makehumancommunity/mpfb2 /tmp/mpfb2`.

```bash
./cast.sh                 # player + ped_01..ped_19 בתיקייה assets/characters (JOBS=4 לבנייה מקבילית, כ-3 דקות)
./cast.sh ped_07 ped_12   # רק דמויות מסוימות
cd ../.. && godot --headless --import . && python3 tools/chargen/fix_imports.py && godot --headless --import .
```

`fix_imports.py` מעביר את הטקסטורות שגודו מחלץ מה-glb (jpg ו-png) לדחיסת VRAM (ETC2/ASTC בטלפון) ומסמן את מפות הנורמל.

## הליהוק

16 הולכי רגל מגוונים (גילאים 25-75, מוצא מעורב, צורות פנים שונות), השחקן (איכות גבוהה), ושני ארכיטיפים חדשים:
`ped_17` מראה טקטי (אפוד קרמי עם כיסים, קסדה, כפפות, מכנסי דגמ"ח עם מגני ברכיים, מגפיים, הסוואה מקורית) ו-`ped_18` / `ped_19` מראה כנופיית רחוב (גופייה, בנדנה, שרשרת, קעקועים, כובע הפוך, מכנסי טרנינג).
הכול מקורי ובלי סמלים, כיתובים או מותגים. השחקן לובש בגדים בהירים וניטרליים כי חנות הבגדים צובעת אותם.

## מה כל דמות כוללת

* **גוף ופנים**: גוף MakeHuman עם 53 עצמות (`game_engine`, שמות העצמות לא משתנים). פרופורציות קצת "אידיאליות" (0.72). הגוף מצומצם (decimate) לפני חיתוך הבגדים, כך שלפנים נשאר בערך שליש מהמשולשים.
* **עור** (1024, לשחקן 2048): גוון בסיס עם כתמיות, אדמומיות בלחיים ובאף, צל מתחת לעיניים, נמשים, שפתיים/שפתון, ציפורניים, כתמי גיל, ו-AO שנאפה ב-Cycles. אחרי בניית הגוף נאפית **מפת מיקום** של העור, וממנה מצוירים לכל פיקסל: גבות בקווי שיער (עולות בצד הפנימי ונוטות החוצה), קו ריסים כהה ורך, קמטי מצח, קמטי צחוק וקפלי אף-פה לפי גיל, זקן/זיפים בקצוות רכים (`stubble / short / full / goatee`), תספורת פייד, וקעקועים. לכל דמות **מפת נורמל** משלה (נקבוביות, קמטים, קווי שפתיים, גבות) ו**מפת חספוס** (אזור T שמנוני, שפתיים מבריקות, ציפורניים).
* **עיניים**: קשתית בסיבים רדיאליים עם "קריפטות" וטבעת לימבלית, אישון, לובן עם ורידים ופינות כהות. לשחקן גם **קרנית שקופה ומבריקה** שבולטת מעל הקשתית (`cornea`). ריסים מהגאומטריה של MakeHuman.
* **שיער**: `bald / buzz / fade / short / slick / curly / medium / long / ponytail / bun`. מעטפת שיער עם טקסטורת סיבים, ובשוליה **שוליים של קצוות שיער** (hair cards עם שקיפות) שנופלים על העור, כך שקו השיער רך ולא "קסדה". שיער ארוך הוא וילון שנגמר בקצוות מרופטים. בגודו החומר מוחלף ב-`player/hair.gdshader` (אותה עלות, alpha scissor שעובד גם ב-Mobile).
* **בגדים**: `tshirt / longsleeve / tank / jacket / leather / suit / hoodie / dress`, מכנסיים `jeans / trousers / chinos / cargo / sweats / shorts / skirt`, ואפוד קרמי (`vest`). כל הבגדים חולקים טקסטורה אחת לכל דמות, שמצוירת ממפת מיקומים שנאפתה על הבגד הסופי: פסים, משבצות, הדפס, הסוואה, חליפה עם דשים ועניבה, מעיל עור מבריק עם רוכסן, כיסים, תפרים, דהייה וקמטים של ג'ינס. יש לה גם **מפת נורמל** (אריג, קפלים במרפקים, מאחורי הברכיים ובקרסוליים, תפרים) ו**מפת חספוס** (עור מבריק, כותנה מט).
* **נעליים וכפפות**: `sneakers` / `boots` / `flats`, כפפות (`gloves`).
* **אביזרים**: משקפיים (`clear` / `sun`), כובע מצחייה (`cap`, `cap_back`), כובע גרב, קסדה, בנדנה, שרשרת, תיק גב.
* **LOD למרחק**: בכל הולך רגל יש רשת שנייה `CharacterLOD` (כ-1,300 משולשים, **חומר אחד**: כל הדמות נאפית לאטלס 512). `human_model.gd` מציג אותה מעבר ל-~20 מ' (12-30 לפי איכות הגרפיקה) עם visibility ranges.
* **תקציב**: הולכי רגל ~8,500 משולשים, השחקן ~14,000; 7-11 חומרים מקרוב, 1 מרחוק.

כל הפרמטרים מתועדים בראש `build_character.py`; הליהוק נמצא ב-`cast.sh`.
