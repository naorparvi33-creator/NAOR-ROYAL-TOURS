# NAOR ROYAL TOURS · האתר

קבצי האתר נמצאים בתיקייה `site`. כל שינוי שנשמר בענף `main` עולה לאוויר לבד דרך Cloudflare Pages.

## הגדרות ב־Cloudflare Pages (פעם אחת)
- **Framework preset:** None
- **Build command:** להשאיר ריק
- **Build output directory:** `site`
- **Production branch:** `main`

## לפני כל עדכון
בקובץ `site/sw.js` מעדכנים את `VERSION`, כדי שמבקרים קבועים יקבלו את הגרסה החדשה מיד.

## Vercel
בשורש המאגר יש `vercel.json` שמגדיר את התיקייה `site` כתיקיית הפלט ואת כל הכותרות (אבטחה ומטמון), כך שאין צורך בהגדרות נוספות.
ב־Vercel: **Add New → Project → Import** של המאגר הזה, ללחוץ **Deploy**. כל דחיפה ל־`main` תעלה לאוויר לבד.

## הצעה חיה (הצעות מחיר ללקוחות)
- **דף הבנייה (רק לנאור):** `/h/build.html`. עובד רק במכשיר שהופעל פעם אחת עם קישור ההפעלה האישי.
- **דף ההצעה (ללקוח):** `/h/#...`. כל פרטי ההצעה נמצאים בתוך הקישור עצמו ולא נשמרים בשום שרת.
- כל הצעה חתומה דיגיטלית. דף ההצעה מציג רק הצעות שנחתמו במפתח שמופיע ב־`site/assets/js/config.js` תחת `proposalKeys`, כך שאי אפשר לזייף הצעה בשם העסק או לשנות בה מחיר.
- קוד ההפעלה (המפתח הפרטי) לא נמצא במאגר ואסור להעלות אותו אליו.
- **קוד חדש או החלפת קוד שנחשף:** בדף הבנייה לוחצים "יצירת קוד הפעלה חדש". הקוד נוצר ונשמר במכשיר בלבד, והדף מציג מפתח ציבורי (לא סודי). את המפתח הציבורי מוסיפים ל־`proposalKeys` ב־`config.js`, ומוחקים משם את המפתח של הקוד שנחשף. הצעות שנחתמו בקוד שהוסר מפסיקות להיפתח, וצריך לשלוח אותן מחדש.
